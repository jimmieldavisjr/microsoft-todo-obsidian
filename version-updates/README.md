# Version updates

What changed in each version of Microsoft To Do for Obsidian, newest first.

| Version | Summary |
| ------- | ------- |
| [1.0.5](v1.0.5.md) | Maintenance release: republishes 1.0.4 with corrected release metadata. No feature changes. |
| [1.0.4](v1.0.4.md) | Full redesign: lists, tasks and details side by side; open it in the main window, the side panel, or both; smart views, search, subtasks, tags and linked notes. |
| [1.0.3](v1.0.3.md) | Sidebar panel with My Day and Important; send notes and selected text to To Do; open a task's source note. |

Each file covers what's new, what changed, and anything to know when upgrading from the version before.
