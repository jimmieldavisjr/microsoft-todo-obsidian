# Version 1.0.3

The baseline that [1.0.4](v1.0.4.md) builds on. Source: commit `2aa4721` ("chore: bump version 1.0.3").

## What it included

- **A sidebar panel** in Obsidian's right sidebar. It could be moved to the left sidebar or into a tab.
- **My Day and Important** views across every list, plus each of your lists with its task count.
- **Adding tasks** from a field at the top of the panel, with a due date, an importance flag and, in My Day and Important, a choice of list.
- **Completing, reopening, renaming and deleting** tasks, and editing a task's notes.
- **Open in Microsoft To Do** on the web for any task.
- **Tasks from your notes**: *Add current note as task* and *Add selected text as task*, with an optional link back to the note.
- **Selected text as a task link** (new in 1.0.3, optional): replaces the selection with a link to the task it created.
- **Open source note** (new in 1.0.3): jump from a task back to the note it was created from.
- **Commands**: Open, Open My Day, Add task, Add selected text as task, Add current note as task, Refresh, Sign in, Sign out.
